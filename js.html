Exemplo 2: Variáveis (Armazenando Dados)

Variáveis são usadas para guardar informações. Usamos let e const para declará-las.

Código JavaScript:

let nome = "Dev Júnior";
const ano = 2025;

// Combinando e exibindo os dados na tela
document.getElementById('resultado-var').innerText = 
  `Olá, ${nome}! Estamos no ano de ${ano}. Variáveis funcionam!`;
