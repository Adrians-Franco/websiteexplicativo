Node.js — Criando o lado do servidor

Voltar Início

O Node.js permite executar JavaScript no servidor e criar APIs.

Exemplo de servidor simples:

const express = require('express');
const app = express();
app.get('/', (req, res) => res.send('Olá do Node.js!'));
app.listen(3000, () => console.log('Rodando em http://localhost:3000'));

Você executa esse código no terminal com:

node index.js
