O que é React?

React é uma biblioteca JavaScript criada pelo Facebook para construir interfaces de usuário de forma eficiente e reutilizável. Ela permite criar componentes que gerenciam seu próprio estado e se atualizam automaticamente quando os dados mudam.

React usa um conceito chamado Virtual DOM, que otimiza as atualizações na página, tornando as aplicações mais rápidas e responsivas.

Componentes React

Componentes são blocos reutilizáveis de UI:

// Componente funcional
function Botao({ texto, onClick }) {
  return (
    <button onClick={onClick}>
      {texto}
    </button>
  );
}

// Usando o componente
export default function App() {
  return (
    <div>
      <Botao 
        texto="Clique em mim" 
        onClick={() => alert("Clicado!")} 
      />
    </div>
  );
}

State e Props

Props

Props são argumentos passados para componentes (dados que vêm de fora).

State

State é dados internos do componente que podem mudar.

import { useState } from 'react';

function Contador() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>Contador: {count}</p>
      <button onClick={() => setCount(count + 1)}>
        Incrementar
      </button>
    </div>
  );
}

Hooks Principais

useState

Adiciona estado a componentes funcionais.

useEffect

Executa efeitos colaterais (fetch, timers, etc).

useContext

Acessa contexto compartilhado entre componentes.

useRef

Cria referências para elementos DOM.

Exemplo: Buscando Dados

import { useState, useEffect } from 'react';

function ListaUsuarios() {
  const [usuarios, setUsuarios] = useState([]);
  const [carregando, setCarregando] = useState(true);

  useEffect(() => {
    fetch('https://api.exemplo.com/usuarios')
      .then(res => res.json())
      .then(dados => {
        setUsuarios(dados);
        setCarregando(false);
      });
  }, []); // Executa apenas uma vez

  if (carregando) return <p>Carregando...</p>;

  return (
    <ul>
      {usuarios.map(usuario => (
        <li key={usuario.id}>{usuario.nome}</li>
      ))}
    </ul>
  );
}
