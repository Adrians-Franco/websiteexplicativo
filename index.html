Introdução ao Conteúdo

O desenvolvimento web moderno é dividido em três pilares principais: **Estrutura**, **Estilo** e **Interatividade**. As tecnologias que você verá aqui cobrem desde o front-end (o que o usuário vê) até o back-end (o que roda no servidor).

O que eu aprendi

  • ✅ **HTML (Estrutura):** A linguagem base para organizar o conteúdo de uma página.
  • 🎨 **CSS (Estilização):** Adicionar cores, formas, layouts e tipografia.
  • ⚙️ **JavaScript (Lógica):** O motor que torna o site dinâmico e interativo.
  • ⚛️ **React (Interfaces):** Criar componentes reutilizáveis para montar aplicações complexas.
  • 🖥️ **Node.js (Back-end):** Usar JavaScript no lado do servidor para criar APIs e gerenciar dados.
