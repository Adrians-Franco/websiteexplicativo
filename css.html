CSS — Estilizando com cores e formas

Voltar Próxima: JavaScript

O CSS é usado para deixar a página bonita e organizada.

Exemplo: Cores e Formas (A Caixa)

.caixa {
  background-color: lightblue;
  padding: 10px;
  border-radius: 8px;
}
Eu sou uma caixa estilizada com CSS 🎨

Tipografia e Fontes

O CSS também permite controlar o estilo do texto, como a fonte, o tamanho e o peso (negrito).

Exemplo: Estilizando Texto

.texto-estilizado {
  font-family: Arial, sans-serif;
  font-size: 18px;
  font-weight: bold;
  color: #333333; /* Cor escura para o texto */
}

Este texto está com uma fonte diferente, maior e em negrito! ✒️
