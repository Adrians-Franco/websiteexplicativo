O que é CSS?

CSS (Cascading Style Sheets) é uma linguagem usada para descrever como elementos HTML devem ser exibidos. Enquanto HTML fornece a estrutura, CSS adiciona cores, fontes, espaçamento, animações e muito mais.

CSS permite que você crie designs bonitos e responsivos, adaptando-se a diferentes tamanhos de tela e dispositivos.

Formas de Usar CSS

1. CSS Inline

<p style="color: blue; font-size: 18px;">Texto azul</p>

2. CSS Interno

<style>
  p { color: blue; font-size: 18px; }
</style>

3. CSS Externo (Recomendado)

<link rel="stylesheet" href="estilos.css">

Seletores CSS

Seletor de Elemento

p { color: blue; }

Seletor de Classe

.destaque { background-color: yellow; }

Seletor de ID

#header { background-color: navy; }

Propriedades CSS Importantes

color

Define a cor do texto.

background-color

Define a cor de fundo.

font-size

Define o tamanho da fonte.

margin e padding

Controlam espaçamento externo e interno.

display

Define como o elemento é exibido (block, inline, flex, grid).

Exemplo Prático

/* Estilos CSS */
body {
  font-family: Arial, sans-serif;
  background-color: #f0f0f0;
  margin: 0;
  padding: 20px;
}

.container {
  max-width: 800px;
  margin: 0 auto;
  background-color: white;
  padding: 20px;
  border-radius: 8px;
}

h1 {
  color: #333;
  text-align: center;
}

button {
  background-color: #007bff;
  color: white;
  padding: 10px 20px;
  border: none;
  border-radius: 4px;
  cursor: pointer;
}

Curiosidades

Cascata

O "C" em CSS significa Cascata, pois estilos são aplicados em cascata.

Responsividade

Media queries permitem adaptar estilos para diferentes tamanhos de tela.

Flexbox e Grid

Ferramentas poderosas para criar layouts complexos e responsivos.
