O que é JavaScript?

JavaScript é uma linguagem de programação que adiciona interatividade às páginas web. Enquanto HTML fornece estrutura e CSS fornece estilo, JavaScript adiciona comportamento e lógica.

JavaScript é executado no navegador do usuário, permitindo criar experiências interativas sem precisar recarregar a página.

Variáveis e Tipos de Dados

JavaScript tem vários tipos de dados:

// Strings
let nome = "João";

// Números
let idade = 25;
let altura = 1.75;

// Booleanos
let ativo = true;

// Arrays
let cores = ["vermelho", "azul", "verde"];

// Objetos
let pessoa = {
  nome: "Maria",
  idade: 30,
  cidade: "São Paulo"
};

Funções

Funções são blocos de código reutilizáveis:

// Função tradicional
function saudacao(nome) {
  return "Olá, " + nome + "!";
}

// Função seta (Arrow Function)
const soma = (a, b) => {
  return a + b;
};

// Chamando a função
console.log(saudacao("Pedro"));
console.log(soma(5, 3)); // 8

Manipulação do DOM

JavaScript pode acessar e modificar elementos HTML:

// Selecionar elementos
const titulo = document.getElementById("titulo");
const botoes = document.querySelectorAll(".botao");

// Modificar conteúdo
titulo.textContent = "Novo Título";

// Adicionar classes
titulo.classList.add("destaque");

// Adicionar event listeners
botoes.forEach(botao => {
  botao.addEventListener("click", () => {
    console.log("Botão clicado!");
  });
});

Eventos Comuns

click

Disparado quando um elemento é clicado.

submit

Disparado quando um formulário é enviado.

change

Disparado quando um input muda de valor.

keydown / keyup

Disparado quando uma tecla é pressionada ou solta.

mouseover / mouseout

Disparado ao passar o mouse sobre um elemento.

Exemplo Prático: Contador

let contador = 0;

const botaoIncrementar = document.getElementById("incrementar");
const botaoDecrementar = document.getElementById("decrementar");
const display = document.getElementById("display");

botaoIncrementar.addEventListener("click", () => {
  contador++;
  display.textContent = contador;
});

botaoDecrementar.addEventListener("click", () => {
  contador--;
  display.textContent = contador;
});
